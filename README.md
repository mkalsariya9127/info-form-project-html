# 📋 Smart Inquiry & Registration Portal

A multi-page responsive web portal featuring user registration, service overview, and contact inquiry systems built with Bootstrap 5 and semantic HTML5.

---

## 🚀 Live Demo & Preview
👉 **[View Live Portal on GitHub Pages](https://mkalsariya9127.github.io/info-form-project-html/)**

---

## 🌐 Included Pages
- **Home (`index.html`):** Overview of the portal, key features, and call-to-actions.
- **Services (`service.html`):** Detailed breakdown of available offerings and services.
- **About (`about.html`):** Information regarding the organization and mission.
- **Contact & Inquiry (`contact.html`):** Comprehensive inquiry and registration form with validation.

---

## ✨ Features
- **Responsive Bootstrap 5 Layout:** Adapts smoothly across desktops, tablets, and smartphones.
- **Form Controls:** Clean input fields, dropdowns, and checkboxes with validation styling.
- **Multi-page Architecture:** Consistent navigation header, brand logo, and footer across all pages.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic structure and form elements
- **Bootstrap 5:** Grid system, responsive utilities, and pre-built UI components
- **CSS3:** Custom color scheme and typography
